# 第 5 章：TD学习笔记

核心：**智能体一边走路，一边根据刚刚发生的事情，修正自己对“以后能拿多少奖励”的估计。**

Sarsa 和 Q-learning 算法都是在学一张表：`Q_table[state, action]`。其主要学习的是**动作价值函数** `Q(s, a)`，不是只看状态的 `V(s)`。

---

## 1. 环境理解

### 1.1 状态 `s`

状态就是智能体当前看到的局面。

在悬崖漫步 Cliff Walking 中，1个格子就是1个状态。例如代码里的环境是 `4 x 12`：则一共有 `48` 个状态；状态编号规则是：`state = 行号 * 列数 + 列号`；起点是 `36`；悬崖是 `37` 到 `46`；终点是 `47`。

状态 `s` 可以理解为：**我现在站在哪个格子上**。

### 1.2 动作 `a`

动作就是智能体现在可以做什么。

本章代码里动作有 4 个：`action_meaning = ['^', 'v', '<', '>']`，含义是： `0`：向上；`1`：向下； `2`：向左； `3`：向右；

动作 `a` 可以理解为：**我下一步往哪个方向走**。

### 1.3 奖励 `r`

奖励就是环境对这一步行为的反馈。

例如悬崖漫步中： 正常走一步通常会有小惩罚，比如 `-1`； 掉进悬崖会有大惩罚，比如 `-100`；到达终点，回合结束。

强化学习不是直接告诉智能体“正确答案是什么”，而是通过奖励告诉它：**刚才这样走，结果好不好**。

### 1.4 策略 `pi`

策略就是智能体选动作的规则。

例如：看到状态 `s` 后，选择动作 `a`；在 `epsilon-greedy` 中，大多数时候选当前看起来最好的动作，少数时候随机探索。

代码里对应的函数是：`def take_action(self, state)`，这个函数的主要作用是：有 `epsilon` 的概率随机选一个动作，用来探索；有 `1 - epsilon` 的概率选 `Q_table[state]` 中价值最大的动作。

---

## 2. 状态价值函数与动作价值函数


### 2.1 状态价值函数 `V(s)`：这个位置本身好不好？

`V(s)` 只问一个问题：我站在状态 `s`，以后大概能拿到多少总奖励？它只看状态，不指定当前动作。

比如：在悬崖漫步中，我站在起点 `36`，如果按照某个策略继续走，最后大概会得到多少奖励？这就是 `V(36)` 想回答的问题。

### 2.2 动作价值函数 `Q(s, a)`：在这个位置做这个动作好不好？

`Q(s, a)` 问得更具体： 我站在状态 `s`，如果现在先执行动作 `a`，之后再按照策略继续走，以后大概能拿到多少总奖励？

比如： `Q(36, 0)`：在起点向上走好不好？；`Q(36, 1)`：在起点向下走好不好？；`Q(36, 3)`：在起点向右走好不好？；`Q(36, 2)`：在起点向左走好不好？ 

这就比 `V(s)` 更适合直接用来选动作。因为如果我已经知道：`Q(36, 上)=-15, Q(36, 下)=-20, Q(36, 左)=-18, Q(36, 右)=-100` ，那我自然会选 `Q` 最大的动作，也就是当前看来最好的动作。

### 2.3 Sarsa算法和Q-learning算法的目的

Sarsa算法和Q-learning算法学的是动作价值函数 `Q(s, a)`， 即`self.Q_table = np.zeros([nrow * ncol, n_action])`

这张表的形状是：`状态数量 x 动作数量`，在 Cliff Walking 中就是：`48 x 4`

所以 `Q_table[36, 3]` 的意思就是：在状态 `36`，执行动作 `3` 的价值，也就是 `Q(s, a)`。

因此，从实际数据结构和更新公式看，这里更新的是**动作价值函数**。

## 3. 时序差分 TD

TD 是 Temporal Difference，中文叫**时序差分**。

它的核心思想是：不用等整局游戏结束才学习，而是每走一步，就用“当前奖励 + 下一步估计价值”来修正当前估计。

### 3.1 Monte Carlo 核心思路

Monte Carlo 方法通常要等一整条轨迹结束，才能知道这次从头到尾到底拿了多少回报。

比如一局走完后，才知道：`本局总回报 = -17`，然后再回头更新前面经过的状态或动作。

这就像考试结束后，拿到总分，再回头总结哪里做得好、哪里做得差。

### 3.2 TD 核心思路

TD 更像边走边改。

走一步之后，马上得到：`当前状态 s 当前动作 a 即时奖励 r 下一个状态 s'`

然后就可以更新：`旧估计：Q(s, a) 和 新参考：r + gamma * 下一步的估计价值`

注意这里的“下一步的估计价值”不一定是真实最终答案，它也是当前表里的估计值。

这就是 TD 的特点：用已有估计去更新另一个估计。这个特点叫 bootstrap，可以理解成“拿自己目前的判断当参考答案的一部分”。

### 3.3 TD 误差

TD 误差就是：`TD误差 = TD目标 - 旧估计`

也就是：我原来以为 Q(s, a) 是这么多；现在走了一步后，发现新的参考答案是另一回事；两者的差距就是 TD 误差。

更新时不是一下子完全相信新目标，而是用学习率 `alpha` 慢慢修正：`Q(s, a) <- Q(s, a) + alpha * TD误差`

其中：`alpha`：学习率，表示每次改多少。

`gamma`：折扣因子，表示未来奖励的重要程度（ `gamma` 越接近 `1`，越重视长期奖励；`gamma` 越接近 `0`，越只看眼前奖励）。

## 4. Sarsa 算法

Sarsa 这个名字来自一条更新链：`S, A, R, S', A'`

也就是：`当前状态s 当前动作a 得到奖励r 下一个状态s' 下一个动作a'`

### 4.1 Sarsa 的更新公式

`Q(s, a) <- Q(s, a) + alpha * [r + gamma * Q(s', a') - Q(s, a)]`

其中 TD 目标：`r + gamma * Q(s', a')`

TD 误差：`r + gamma * Q(s', a') - Q(s, a)`

对应代码：

```python
td_error = r + self.gamma * self.Q_table[s1, a1] - self.Q_table[s0, a0]
self.Q_table[s0, a0] += self.alpha * td_error
```

最关键的是 `a1`，`a1` 是智能体在下一个状态 `s1` 中**真实选出来的下一个动作**。

### 4.2 在策略 on-policy

Sarsa 学的是自己实际执行的策略。

训练流程：

- 先用 `take_action(state)` 选当前动作。
- 执行动作，得到 `next_state` 和 `reward`。
- 再用同一个策略 `take_action(next_state)` 选 `next_action`。
- 更新时用实际选出来的 `next_action`。

由此 Sarsa 的学习目标带着探索策略本身的影响，如果 `epsilon-greedy` 有概率乱走，那么 Sarsa 在估计价值时会把“以后可能继续乱走”也考虑进去。

### 4.3 Sarsa 的特点

在悬崖漫步中，Sarsa 往往更保守。

因为它知道：我虽然大多数时候会选最优动作，但偶尔会因为探索随机走一步。

如果贴着悬崖走，随机探索时很容易掉下去，所以 Sarsa 可能学到一条离悬崖远一点的路线。

这不是因为 Sarsa 不聪明，而是因为它学的是“带探索行为的实际策略”。

## 5. Q-learning 算法

Q-learning 和 Sarsa 很像，也更新 `Q(s, a)`，但它的 TD 目标不一样。

### 5.1 Q-learning 的更新公式

`Q(s, a) <- Q(s, a) + alpha * [r + gamma * max_a Q(s', a) - Q(s, a)]`

其中 TD 目标：`r + gamma * max_a Q(s', a)`

TD 误差：`r + gamma * max_a Q(s', a) - Q(s, a)`

对应代码：

```python
td_error = r + self.gamma * self.Q_table[s1].max() - self.Q_table[s0, a0]
self.Q_table[s0, a0] += self.alpha * td_error
```

关键区别是：`self.Q_table[s1].max()`，它不是问下一步我实际选了哪个动作？而是问：如果下一步我总能选最好的动作，那么价值是多少？

### 5.2 离策略 off-policy

Q-learning 行为上仍然会和环境一步一步交互，也会用 `epsilon-greedy` 探索，所以它不是“不在线交互”。它依然是在线采样数据。

但它更新时学习的目标策略，不是当前这个带随机探索的行为策略，而是假设下一步直接选择最大 `Q` 值的贪心策略。

也就是说：行为策略用 `epsilon-greedy` 选动作，负责探索环境，目标策略用 `max_a Q(s', a)`，假设以后选择最优动作。

行为策略和目标策略不完全一样，所以叫**离策略 off-policy**。

### 5.3 Q-learning 的特点

在悬崖漫步中，Q-learning 往往更激进。因为它更新时总是假设下一步会选择最好的动作。所以它可能学到一条更贴近悬崖的最短路线，这条路线理论上更短，但训练时如果还在探索，就可能因为随机动作掉进悬崖。

---

## 6. Sarsa 和 Q-learning 的核心区别

两者最大的区别不在训练循环表面，而在 TD 目标。

| 对比点 | Sarsa | Q-learning |
| --- | --- | --- |
| 学习对象 | `Q(s, a)` | `Q(s, a)` |
| 是否与环境交互 | 是 | 是 |
| 当前动作怎么选 | `epsilon-greedy` | `epsilon-greedy` |
| 下一步价值用什么 | 实际选出的 `Q(s', a')` | 最优动作的 `max_a Q(s', a)` |
| 策略类型 | 在策略 on-policy | 离策略 off-policy |
| 直观风格 | 更考虑探索风险，偏保守 | 更接近最优贪心路线，偏激进 |
